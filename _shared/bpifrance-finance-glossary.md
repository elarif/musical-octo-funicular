# Glossaire Bpifrance — Prévisions financières et business plan

Termes français utilisés par les 6 skills `previsions-financieres-demarrage`, `plan-financement-durable`, `tresorerie-bfr`, `seuil-rentabilite`, `business-plan-redaction`, `executive-summary`.

| Terme | Définition |
|---|---|
| BFR | Besoin en fonds de roulement — décalage de trésorerie entre dépenses et recettes d'exploitation |
| CAF | Capacité d'autofinancement = bénéfices après impôts + dotations aux amortissements |
| Charges fixes | Charges structurelles indépendantes du CA (loyer, salaires, assurances) |
| Charges variables | Charges opérationnelles liées au CA (approvisionnements, transport, commissions) |
| Seuil de rentabilité | Niveau de CA au-delà duquel l'entreprise fait un bénéfice (€) |
| Point mort | Moment (temps) où le seuil de rentabilité est atteint (jours/mois) |
| Plan de financement initial | Tableau besoins/ressources durables au jour zéro |
| Plan de financement à 3 ans | Projection besoins/ressources durables N/N+1/N+2 |
| Plan de trésorerie | Tableau encaissements/décaissements mensuels sur 12 mois |
| Executive summary | Résumé opérationnel 1-2 pages en ouverture du business plan |
| Business plan | Dossier structuré présentant le projet de création (8 sections) |
| TVA collectée | Taxe sur la valeur ajoutée encaissée sur les ventes |
| TVA déductible | TVA payée sur les achats, récupérable |
| TVA à décaisser | TVA collectée - TVA déductible, reversée à l'État (mois M+1) |
| Franchise en base de TVA | Régime d'exonération de TVA sous seuils (micro-entreprise, etc.) — TVA = 0 |
| MRR | Monthly Recurring Revenue (SaaS) |
| ARR | Annual Recurring Revenue (SaaS) |
| CAC | Customer Acquisition Cost |
| LTV | Lifetime Value d'un client |
| Churn | Taux d'attrition (perte de clients abonnés) |
| CapEx | Capital Expenditure — investissement durable |
| OpEx | Operational Expenditure — dépense récurrente (cloud, API) |
| Matrice des risques | Zones fragiles + points de rupture à retravailler (remplace go/no-go) |
| state-tool.sh | Script bash+jq gérant le state JSON (init/get/set/patch/snapshot) |
